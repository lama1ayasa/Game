# 🎮 Word Guessing Game

لعبة تخمين كلمات تنافسية لشخصين على نفس الجهاز، بأسلوب شبيه بـ **Wordle**، لكن مع نظام أدوار ونقاط بين اللاعبين.

## ✨ Features

* 👥 لعب لشخصين على نفس الجهاز.
* 🌐 دعم **العربي والإنجليزي**.
* 📂 عدة فئات: حيوانات، فواكه، دول، ألوان، مهن ورياضات.
* 🎲 اختيار الكلمات بشكل عشوائي.
* 🟩🟧⬜ نظام ألوان لتقييم التخمين.
* ⭐ نظام نقاط تنافسي.
* ⏱️ تايمر اختياري لكل دور.
* 🌙☀️ Dark Mode & Light Mode.
* 📱 Responsive Design للموبايل والكمبيوتر.
* 🏆 شاشة نتائج وتحديد الفائز.
* 🔄 إمكانية اللعب مرة ثانية.
* 💾 حفظ إعدادات الثيم باستخدام LocalStorage.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* LocalStorage

## 🚀 تشغيل المشروع

المشروع **Front-End فقط** وما يحتاج أي Server.

1. حمّل المشروع.
2. افتح ملف `index.html`.
3. ابدأ اللعب 🎮

## 🎯 الهدف

الهدف من اللعبة هو تخمين الكلمة السرية قبل اللاعب الثاني وجمع أكبر عدد ممكن من النقاط.
